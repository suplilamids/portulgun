Infinite Portal Gun (Fabric 1.20.1)
Build:  install JDK 17, then in this folder run:  gradle build   (or open in IntelliJ and run "build")
        Result: build/libs/portalgun-1.0.0.jar  -> put in your mods folder with Fabric API.
Use:    Get it with:  /give @s portalgun:portal_gun   (or craft it)
        Right click = choose X Y Z D and Save.  Left click = open portal (20s). Walk in.
        D=0 Overworld, any other number = its own generated dimension (same number = same dimension every time).
